# Projectile Modifier

Выбирайте снаряды, размер залпа и интервалы автоматической стрельбы для всех 77 типов юнитов. Катапульты могут стрелять камнями мангонели, а осадные башни и бойцы ближнего боя — получить автоматическую дальнюю атаку.

**Balance Changes → Снаряды**

Раскройте группу, затем юнита. Отметьте меч, чтобы изменить числовое значение; раскройте настройку, чтобы прочитать подсказку. Отключённые настройки сохраняют значения из файла или исходное поведение. Для применения изменений перезапустите игру.

Включает автоматическую стрельбу, в том числе для бойцов ближнего боя и осадных башен. По умолчанию заменяет исходные выстрелы. Используется исходный снаряд, а при его отсутствии — стрелы. Тик — шаг симуляции, а не миллисекунда.

Цели автоматической стрельбы. Союзные юниты и здания исключены. Стены включают и ваши собственные. Свой порядок приоритетов можно задать в файле YAML.

Загрузите файл YAML для расширенных настроек: движения, последовательных залпов, точности, высоты и анимации. Включённые ниже настройки заменяют значения из файла. Без файла доступны основные настройки. Примеры и полная таблица приведены в README.md; схема для редактора — projectile-config.schema.json.

Требуются UCP 3.0.7+, map-extensions 1.x и Crusader/Extreme 1.41. Таймеры и ожидающие залпы сохраняются; для загрузки нужны совпадающие настройки. Эта неподписанная тестовая версия 1.3.2 основана на версии 1.2.0 от Monsterfish. Проверки в игре, сетевом режиме и с модулем записи ещё предстоят; см. VALIDATION.md.
