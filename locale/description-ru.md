# Custom Projectiles 1.8.16

range ограничивает расстояние до выбранной цели в клетках, даже при штатной перезарядке. spread и inaccuracy могут смещать попадания за этот радиус. strict_range: false отключает исправление дальности при ручном выборе цели.

Замены для большой дальности: projectile_physics: {firethrower_pot: {mode: fixed_angle, angle: 30}} позволяет игре вычислять скорость запуска. Нужен активный Rebalancer 1.1.3+ с баланс-конфигурацией. Настройка глобальна для типа, включая свои спрайты; native сохраняет значения. Дальность выбора цели и столкновения по-прежнему действуют.

Настройки игрового поведения можно менять перед загрузкой; старые очереди выстрелов и таймеры модуля сбрасываются. Определения своей графики должны совпадать. allow_config_changes_on_load: false требует исходные настройки. strict_range: false также отключает новую проверку дальности ручных выстрелов.

Автоматические боеприпасы: задайте списки целей в unit_groups, затем ammo_by_target.groups: {siege: regular} для стрелка или ammo_by_target.units: {Monk: cow}. Точные типы важнее групп; прочие цели без изменений. Нужен интервал; native удаляет правила. Пример Reconquista включён.

Настройка всех 77 типов юнитов через YAML. Обычные снаряды и коровы настраиваются отдельно. Интервалы учитывают поддерживаемые анимации стрельбы; inaccuracy измеряется в единицах игры: 1 = 1/8 клетки, 8 = 1 клетка, 0 = точное прицеливание.

Ограничение по числу целей в группе действует только для ИИ; игрок может задавать цель атаки вручную. При автоматическом выборе юнитов target_bias_tiles: {Monk: 3} уменьшает расстояние до монахов в штатной оценке максимум на три клетки; дальность и остальные правила сохраняются.

Скопируйте полный файл vanilla-projectiles.yml из ZIP, измените и выберите копию. native сохраняет правила игры; пустой путь ничего не меняет. auto_targeting: false разрешает только ручные приказы атаки. strict_range: false возвращает округлённую проверку дальности; turn_before_shot: false отключает исправление поворота. Обязательное/рекомендуемое применяется к выбору файла целиком. После изменений перезапустите игру.

Своя графика: добавьте имя в projectiles с inherits и sprites (полный совместимый файл GM1). Задайте decorations и правила near_decorations для юнитов; размещайте объекты кнопкой жаровни. Форматы: README.md и examples/custom-sprites-and-decorations.yml. Стройте на подходящих стенах или башнях; на усадьбах жаровни не размещаются.

Нужны UCP 3.0.7+, Crusader/Extreme 1.41 и зависимости модуля. Тестовая версия; см. VALIDATION.md.
