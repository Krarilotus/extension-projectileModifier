# Custom Projectiles 1.6.0

Выбирайте снаряды, размер залпа и интервалы автоматической стрельбы для всех 77 типов юнитов. Катапульты могут стрелять камнями мангонели, а осадные башни и бойцы ближнего боя — получить автоматическую дальнюю атаку.

Скопируйте vanilla-projectiles.yml из ZIP модуля в ucp/resources/custom-projectiles/, отредактируйте копию и выберите её здесь. Пропущенные настройки не меняются; пустой путь не вносит изменений. Правила UCP для обязательных и рекомендуемых значений применяются ко всему выбранному файлу. После изменений перезапустите игру.

Требуются UCP 3.0.7+, map-extensions 1.x и Crusader/Extreme 1.41. Все 33 настройки и 77 названий юнитов описаны в vanilla-projectiles.yml и README.md. Локальная тестовая версия; проверка в игре ещё предстоит.

Точность: inaccuracy использует целые единицы координат игры: 1 = 1/8 клетки, 8 = 1 клетка. 0 убирает случайную ошибку; без параметра сохраняется исходная точность. spread действует отдельно.

Для катапульт, требушетов, мангонелей и баллист interval учитывает анимацию выстрела и не сокращает её. sync_to_animation: false возвращает независимый таймер. После обновления начните новую игру.
