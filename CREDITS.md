# Credits

Custom Projectiles is Krarilotus' module (GitHub: Krarilotus).

Monsterfish (GitHub: Monsterfisch) wrote the original 1.2.0 module this one
grew from, and contributed ideas and code to later versions, including:

- the Reconquista settings, now planned as their own plugin;
- starting alongside Smarter Walls, Improved Siegeengines and Improved
  Tunnelers at shared code sites (his 1.8.17);
- loading saves and maps after settings, graphics or edition changes instead
  of refusing them (his 1.8.18).

Monsterfish agreed on 22 November 2026 that Custom Projectiles is Krarilotus'
module with his ideas and contributions, and that his contributions are covered
by the same license as the rest of the module. The repository has no license
file yet; choosing the license is Krarilotus' decision.

Original game: Firefly Studios. Framework, save, resource and protocol APIs:
the Unofficial Crusader Patch contributors. OpenSHC reconstruction provides
research references; reference addresses are not production bindings.
